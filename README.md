# trabalho-agenda
Trabalho da disciplina de AeD 1 de CC da UFPel.

Aluno: Felipe Reichow Mareque;
Turma: M1;
Este projeto consiste no desenvolvimento de uma agenda simples em linguagem C, onde é possível adicionar, remover, buscar e listar pessoas com nome, idade e e-mail. O diferencial da implementação é que toda a estrutura de dados é construída manualmente a partir de um único bloco de memória (pBuffer), simulando o gerenciamento de memória feito pelo sistema operacional. Dessa forma, não são utilizadas estruturas prontas como structs ou arrays fixos, exigindo controle direto sobre alocação e organização dos dados.
